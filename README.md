# BookManagement — Java Swing + MySQL

## Project Structure

```
BookManagement/
├── bookmanagement_setup.sql          ← Run this in MySQL first
└── src/
    └── bookmanagement/
        ├── DatabaseConnection.java   ← Singleton DB connection
        ├── Manageable.java           ← Interface (OOP: Abstraction)
        ├── Entity.java               ← Abstract base class (OOP: Abstraction)
        ├── User.java                 ← Subclass of Entity (OOP: Inheritance)
        ├── Book.java                 ← Subclass of Entity (OOP: Inheritance)
        ├── UserDAO.java              ← Implements Manageable<User> (OOP: Polymorphism)
        ├── BookDAO.java              ← Implements Manageable<Book> (OOP: Polymorphism)
        ├── Login.java                ← JFrame: Login screen
        ├── Register.java             ← JFrame: Registration screen
        └── BookRegistration.java     ← JFrame: CRUD + Search screen
```

## OOP Concepts Used

| Concept       | Where Applied                                      |
|---------------|----------------------------------------------------|
| Encapsulation | Private fields + getters/setters in User, Book     |
| Inheritance   | User and Book both extend abstract class Entity    |
| Abstraction   | Entity (abstract class) + Manageable (interface)   |
| Polymorphism  | UserDAO and BookDAO both implement Manageable<T>   |

## Setup Steps

### Step 1 — MySQL
1. Open MySQL Workbench or phpMyAdmin
2. Run the file `bookmanagement_setup.sql`
3. This creates the `bookmanagement` database, `tblusers`, and `tblbooks`
4. Default user: **username:** admin / **password:** admin

### Step 2 — NetBeans / IntelliJ Setup
1. Create a new Java project named **BookManagement**
2. Create a package named **bookmanagement**
3. Copy all `.java` files into `src/bookmanagement/`
4. Add the **MySQL JDBC Driver** (mysql-connector-java) to your project:
   - Download from: https://dev.mysql.com/downloads/connector/j/
   - In NetBeans: Right-click Libraries → Add JAR/Folder
   - In IntelliJ: File → Project Structure → Libraries → Add JAR

### Step 3 — Configure DB Password
Open `DatabaseConnection.java` and update:
```java
private static final String PASSWORD = ""; // ← Enter your MySQL root password here
```
If your MySQL user is not root, update USER too.

### Step 4 — Run
Set **Login.java** as the main class and run the project.

## Features

### Login Form
- Validates credentials against `tblusers`
- Clear button resets fields
- Register button opens the registration form

### Register Form
- Checks for duplicate usernames
- Validates passwords match
- Enforces 10-character limits
- On success, returns to Login

### Book Registration Form
- **ADD** — inserts a new book record
- **UPDATE** — updates selected book (click row first)
- **DELETE** — deletes selected book with confirmation
- **CLEAR** — resets all form fields
- **REFRESH** — reloads all books and clears search
- **Live Search** — filters table by title as you type
- **Row click** — auto-populates form fields for editing
- **Logout** — returns to Login screen

## Notes
- Book ID is auto-generated by MySQL (do not enter manually)
- Status field accepts up to 7 characters (e.g., "Availab" or "Borrow")
- Username and password fields are limited to 10 characters each
